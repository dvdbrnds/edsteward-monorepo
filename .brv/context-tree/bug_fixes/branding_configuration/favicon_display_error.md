Fixed favicon not showing in EdSteward after branding restoration. Root cause: When Moravian branding was restored, only the logo was updated but not the favicon - it remained as "/favicon.ico" instead of "/moravian-favicon.ico". Solution: Updated branding configuration via POST to `/api/admin/branding` endpoint to set `faviconUrl: "/moravian-favicon.ico"`. The `useBranding` hook automatically calls `updateFavicon()` with cache busting (`?v=${timestamp}`) when branding data changes. Verified the Moravian favicon file exists and is accessible at `/moravian-favicon.ico`. Now both logo and favicon display correctly for Moravian University branding.
