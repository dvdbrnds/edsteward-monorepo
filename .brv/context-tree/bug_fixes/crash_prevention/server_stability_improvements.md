EdSteward server crash prevention implemented January 2025. Root cause: Server lacked proper error handling for uncaught exceptions and unhandled promise rejections, causing crashes from database connection issues. Solution: Added comprehensive crash prevention in server/index.ts: 1) process.on('uncaughtException') - logs error but continues server 2) process.on('unhandledRejection') - logs promise rejections but continues 3) Database monitoring every 30 seconds with testConnection() 4) Memory monitoring every 5 minutes with warnings >500MB heap 5) Graceful shutdown handlers for SIGTERM/SIGINT. Server now resilient to database connection failures and other errors that previously caused crashes. Critical for production stability.
