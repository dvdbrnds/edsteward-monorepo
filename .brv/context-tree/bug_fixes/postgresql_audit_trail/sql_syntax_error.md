Fixed critical SQL syntax error in EdSteward audit trail system. The issue was in server/services/audit.ts where `and(...conditions)` was called with an empty array when no filter conditions were provided, causing "syntax error at or near )" in PostgreSQL. Fixed by using `sql`1=1`` as fallback when conditions array is empty, and added sql import from drizzle-orm. This resolved the 500 Internal Server Error on GET /api/audit/logs endpoint.
