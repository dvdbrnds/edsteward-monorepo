Fixed "User is not defined" ReferenceError in EdSteward compliance-tasks feature. Root cause: In `send-attestation-dialog.tsx`, a local `User` interface was defined AND `<User className="h-4 w-4" />` was used as a JSX component expecting a lucide-react icon, but `User` was never imported from 'lucide-react'. The fix was to add `User as UserIcon` to the lucide-react imports and change the JSX usage to `<UserIcon />`. When using lucide-react icons alongside TypeScript interfaces of the same name, always alias one to avoid conflicts. Common pattern: `import { User as UserIcon } from 'lucide-react'` when you also have a `User` type/interface.
