OKTA Administrator Setup Guide: Created comprehensive OKTA_SETUP_GUIDE.md with step-by-step instructions for SAML configuration. Key requirements: Single sign on URL: http://localhost:3000/auth/saml/callback, Audience URI: urn:edsteward:sp, Name ID format: EmailAddress. Critical: Certificate must have proper newlines (not literal \n), URLs must match exactly, user must be assigned to OKTA application. Metadata endpoint found at /auth/saml/metadata for SP configuration.
