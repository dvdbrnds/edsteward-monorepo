EdSteward customer frontend architecture decision (Jan 2026): Vendor admin/tenant management functionality was removed from the customer frontend. The customer frontend is now purely single-tenant focused - it's the product customers deploy on-prem or cloud. Tenant provisioning and management should happen at the MCP Engine backend level, not through a separate admin console frontend. Files removed: admin-dashboard-page, vendor-admin-page, admin-auth-page, aws-tenant-management pages/components, admin-dashboard.ts, aws-tenant-management.ts server routes. The admin-console directory still exists but may become redundant if MCP Engine handles provisioning.
