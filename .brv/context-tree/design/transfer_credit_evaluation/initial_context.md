## TransferIQ Project - Initial Context

**Project**: TransferIQ - Instant Transfer Credit Evaluation Platform for colleges/universities

**Problem Solved**: Transfer students wait days/weeks for credit evaluations. Staff do repetitive manual work. Inconsistent evaluations create confusion.

**Core Features**:
1. Student transcript upload portal (PDF, PESC XML, JSON, SPEEDE EDI)
2. Intelligent data extraction with ML/OCR
3. Two-tier credit evaluation engine (best-practices + institution-specific)
4. Instant results dashboard
5. Admin console with equivalency management
6. CRM/SIS integrations (Slate, Salesforce, Banner, PeopleSoft)

**Technical Requirements**:
- Cloud-native SaaS, multi-tenant
- RESTful API with webhooks
- FERPA compliant, SOC 2 target
- 99.9% uptime SLA
- Results in <30 seconds (structured) / <2 minutes (OCR)
- SSO via SAML 2.0 / OAuth 2.0

**Business Model**: Annual subscription $15K-$90K by FTE tier

**Roadmap**:
- Phase 1: Core platform, PDF extraction, basic matching
- Phase 2: Admin console, review workflows, analytics
- Phase 3: CRM integrations, structured transcripts, SSO
- Phase 4: SIS integrations, degree audit, SOC 2
