## Gold Certification Criteria

For a regulation to be "Gold Certified":

1. **Tasks**
   - [ ] All tasks tied to actual legal requirements
   - [ ] Tasks properly categorized (requirement/best_practice)
   - [ ] No template/generic tasks
   - [ ] Task IDs follow naming convention

2. **Metadata**
   - [ ] Correct regulation name
   - [ ] Accurate statute citation
   - [ ] CFR reference (if applicable)
   - [ ] Not a duplicate of another regulation

3. **Deadlines**
   - [ ] Key deadlines identified
   - [ ] Frequency set correctly
   - [ ] Reporting entity identified (where applicable)

4. **Console**
   - [ ] Console loads without errors
   - [ ] Tasks display correctly
   - [ ] Deadlines display correctly
