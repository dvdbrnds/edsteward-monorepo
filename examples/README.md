# MCP Engine Examples

This directory contains example implementations, test files, and sample code that demonstrate various MCP (Model Context Protocol) concepts and implementations.

## MCP Client Examples

- `sample-mcp-client.js` - Basic MCP client implementation showing how to make calls
- `direct-mcp-client.js` - Direct MCP client with minimal dependencies
- `test-mcp-client.js` / `test-mcp-client.cjs` - Test implementations for MCP clients

## MCP Server Examples

- `simple-mcp-server.cjs` / `simple-mcp-server.mjs` - Basic MCP server implementations
- `test-mcp-server.js` / `test-mcp-server.mjs` - Test MCP server implementations
- `minimal-mcp-server.js` - Minimal server implementation
- `final-mcp-server.cjs` - Final iteration of MCP server
- `mini-mcp-server.cjs` - Compact MCP server implementation

## SDK and Usage Examples

- `mcp-sdk-example.js` - Example using the MCP SDK
- `use-mcp-sdk.js` - Usage patterns for the MCP SDK
- `sample-usage.js` - General usage examples

## Demo and Integration Examples

- `demo-client.js` - Full demo client showing MCP Engine capabilities
- `orchestrator-example.cjs` - Example of MCP orchestration patterns
- `civil-service-act-client.cjs` - Domain-specific client example

## Legacy Files

- `start-registry.cjs` - Alternative registry startup script (legacy)

## Usage

These files are primarily for reference and learning. They show different approaches to implementing MCP clients and servers, and can be used as starting points for your own implementations.

**Note**: These examples may require different dependencies or configurations than the main application.
