Fixed logo not updating in EdSteward navigation header. Root cause: Navigation component in client/src/components/layout/navigation.tsx was using hardcoded `edStewardLogo` import instead of dynamic `branding.logo` from the branding API. Fix: Changed `src={edStewardLogo}` to `src={branding.logo}` in the img tag and removed unused `edStewardLogo` import. This allows the navigation logo to dynamically update based on the branding configuration from the database. Frontend rebuilt and server restarted to apply changes. Now the Moravian University logo should display correctly in the header when branding is configured.
