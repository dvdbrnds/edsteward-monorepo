Fixed critical audit trail 403 Forbidden errors by adding defensive array validation to hasPermission function in server/config/role-mapping.ts. The issue was that userRoles parameter wasn't always an array when passed to hasPermission, causing "TypeError: userRoles.some is not a function". Added Array.isArray() check to ensure roles is always an array before calling .some() method. This resolved the 403 errors on audit trail API endpoints.
