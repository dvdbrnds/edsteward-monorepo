SAML AUTHENTICATION BREAKTHROUGH: Fixed the ASN.1 encoding error with original OKTA certificate! SAML callback now works but encountered "User not found and auto-provisioning is disabled" error. Root cause: AUTH_ALLOW_SELF_REGISTRATION environment variable was missing from docker-compose.dev.yml. Added AUTH_ALLOW_SELF_REGISTRATION=true to Docker Compose config. This enables automatic user provisioning when SAML users authenticate for the first time. SAML authentication should now work end-to-end with automatic user creation.
