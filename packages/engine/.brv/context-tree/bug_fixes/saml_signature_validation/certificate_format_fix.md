SAML CERTIFICATE FORMAT SOLUTION: For EdSteward SAML authentication, the certificate must be cleaned for signature validation by removing PEM headers (-----BEGIN CERTIFICATE----- and -----END CERTIFICATE-----) and all whitespace. The cleaned certificate (Base64 only) should be passed to the `cert` parameter in SamlStrategy. This resolves the "error:0680009B:asn1 encoding routines::too long" error during SAML callback signature validation.
