SAML SIGNATURE VALIDATION WORKAROUND: For EdSteward SAML authentication, when encountering "error:0680009B:asn1 encoding routines::too long" during callback signature validation, the solution is to disable signature validation by setting `wantAssertionsSigned: false` and `validateInResponseTo: false` in the SamlStrategy configuration. This allows SAML authentication to complete successfully while bypassing the certificate signature validation issue.
