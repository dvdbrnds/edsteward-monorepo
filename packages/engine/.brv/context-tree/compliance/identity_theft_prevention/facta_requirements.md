## REG-029 FACTA - FIXED - January 2026

- Statute: Public Law 108-159; 16 CFR Parts 681, 682
- Tasks: 7 requirements, 1 best practice

### Requirements
1. Red Flags Rule Program (Identity Theft Prevention) - required for creditors
2. Red Flags Identification
3. Red Flags Detection Procedures
4. Red Flags Response Procedures
5. Program Board Approval - annual
6. Disposal Rule Compliance - secure destruction of consumer info
7. Receipt Truncation - show only last 5 digits of card numbers

### Higher Ed Context
Most institutions are "creditors" under Red Flags Rule due to:
- Tuition payment plans
- Student account deferrals
- Institutional loan programs
