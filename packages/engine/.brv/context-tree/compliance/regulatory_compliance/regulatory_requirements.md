## REG-030 to REG-033 FIXED - January 2026

### REG-030 FISMA (7 req)
Federal information security for federal data/systems:
- Information Security Program, Risk Assessment, NIST Controls
- Security Training, Incident Response, Continuous Monitoring, POA&M

### REG-031 FOIA (3 req, 1 best)
Limited applicability to private institutions:
- Public Records Policy, Request Procedures, Exemption Determination

### REG-032 GLBA - CRITICAL FOR HIGHER ED (9 req, 1 best)
Safeguards Rule (16 CFR 314) - applies to student financial aid:
- Written Information Security Program
- Qualified Individual Designation
- Risk Assessment, Safeguards Implementation
- Service Provider Oversight
- Program Evaluation, Incident Response Plan
- Board Reporting (annual), Privacy Notice

### REG-033 HITECH (6 req, 1 best)
Extends HIPAA, breach notification focus:
- Breach Notification to Individuals (60 days)
- Breach Notification to HHS (immediate for 500+)
- Media Notification (500+ in state)
- BAA Requirements, Risk Assessment, Documentation
