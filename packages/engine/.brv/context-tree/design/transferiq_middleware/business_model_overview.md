## TransferIQ Business Model - Middleware for Schools

**Core Concept**: TransferIQ is middleware that schools embed on their admission websites. It's NOT a standalone platform students visit directly.

**User Flow**:
1. Prospective transfer student visits school's admission website (e.g., moravian.edu/transfer)
2. School has TransferIQ widget embedded ("See what credits transfer instantly!")
3. Student uploads transcript via widget
4. Gets instant credit evaluation results
5. Results include "Register Now" / "Apply Now" CTA button
6. Button hands student back to school's native enrollment/application system
7. Evaluation results are delivered to admissions staff as a report

**Key Requirements**:
- Embeddable widget (iframe or JS SDK)
- White-label/school branding support
- Export functionality for admissions staff (PDF report, JSON data)
- "Register Now" CTA with configurable redirect URL
- API access for school's backend systems
- Per-school configuration (logo, colors, redirect URLs, messaging)

**Sales Tool**: This is a "top of funnel" instant gratification tool to convert prospective transfer students into applicants.
