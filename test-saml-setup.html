3. OKTA Configuration Checklist

Before testing, configure OKTA:
  1. Create SAML 2.0 application in OKTA
  2. Set Single sign on URL: http://localhost:3000/auth/saml/callback
  3. Set Audience URI: urn:edsteward:sp
  4. Download OKTA certificate and update AUTH_SAML_CERT
  5. Update AUTH_SAML_SSO_URL with real OKTA SSO URL

4. Expected SAML Flow

  1. User clicks "Test SAML Login" → Redirects to OKTA
  2. User authenticates with OKTA
  3. OKTA sends SAML response to /auth/saml/callback
  4. EdSteward processes SAML response and creates/finds user
  5. User is redirected to /dashboard with active session

5. Troubleshooting

Common issues:
• Certificate formatting (ensure proper newlines, not literal \n)
• Callback URL mismatch between OKTA and EdSteward
• Missing or incorrect environment variables
• SAML response signature validation failures

Check server logs for detailed error messages.
